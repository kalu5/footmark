# Linux 

## Base

### 基本语法

命令 -选项 参数（指定命令作用的对象如文件名或路径）
```bash
ls -l /home
```

## 提升效率

1. Tab（补全命令名、文件名、目录路径）
- 单次tab自动补全唯一匹配项
- 双次tab显示所有可能出现的列表，用于存在多项匹配时

2. history历史命令
- 查看历史`history`
- 快速执行：查看历史后通过!编号快速执行如：`!22`
- 快捷切换：通过上下键快捷切换历史

3. 搜索与快速匹配
- Ctrl+R反向搜索（实时匹配历史命令， 输入关键字即可定位，按Enter执行）
- `!!`快速执行（重新执行上一条命令， `sudo!!` -> 快速以管理员权限重试命令）
- `history -c`用于清空当前会话的历史缓存，常用于敏感操作后的痕迹清理或环境初始化，确保操作历史不被泄漏

4. 帮助系统
- `--help`如`ls --help`
- `man`手册如`man ls`查询命令的详细信息
- `tldr`只展示常用的高频实战范例，如`tldr tar`

## 系统目录结构

Linux的哲学：一切皆文件（统一操作接口使用命令全局控制系统）

- /：根目录
- /etc: 系统配置文件（修改记得备份）
   - /etc/hosts: 静态域名解析
   - /etc/passwd: 存储用户信息
   - /etc/skel: 用户创建时系统自动从该目录复制拷贝文件

- /root: 管理员目录

- /home: 用户主目录：个人数据(随意弄不会影响全局)
  - /home/user: 创建一个用户就会生成一个/home/user

- /bin: 二进制可执行文件，通用基础命令（ls、cat等）

- /sbin: 系统管理命令（ip、 fdisk等）

- /dev: 设备目录（硬盘等）

- /usr(Unix system resource): 用户应用程序（软件： 办公、编程软件等）目录，类似windows的Program Files,是系统中最庞大的目录之一
  - /usr/local: 个人软件等
  - /usr/bin: 命令
  - /usr/lib: 库

- /var: 可变数据目录
  - /var/log: 日志
  - /var/mail: 代收发邮件
  - /var/cache: yum缓存

- /opt: 第三方等预编译软件

- /temp: 临时文件

## 目录管理

- pwd: Print Working Directory
  - 显示当前工作目录的绝对路径
  - 在复杂目录结构中快速定位

- cd: Change Directory
  - 切换当前工作目录
  - 语法
    `cd [目标路径（相对/绝对）]`
  - 快捷跳转(`~`: 用户家目录， `-`： 上一次所在目录)
    - `cd ~` / `cd`: 快速回到用户家目录
    - `cd -` : 在两个目录间切换
    - `cd ..` : 返回上一级

- ls: List
  - 列出目录内容
  - 查看当前目录下的非隐藏内容
  - 基础语法`ls [目录路径]`
  - 常用选项(选项可以组合使用： `ls -lah`， `ls -ltr`)
    - `-l`: 长格式显示详细信息
    - `-a`: 包含隐藏文件（以.开头）
    - `-h`: 文件大小易读化（KB/MB）
    - `-t`: 按修改时间排序
    - `-r`: 反转排序结果

- mkdir: Make Directory
  - 创建新目录
  - 语法`mkdir [目录名]`
    - 目录名严格区分大小写
    - 避免使用特殊字符及空格
  - 高级用法
    - `mkdir -p`: 递归创建
      - 普通创建局限：父目录不存在时会报错
      - `-p`(parent选项)：自动补全中间路径
      - 优势：一次性构建完整目录
      - 例子：`mkdir -p project/src/main/java`

- rmdir: Remove Directory
  - 限制：仅能删除空目录
  - 安全：有效防止误删
  - 报错： 目录非空报错

## 文件基本操作

- 核心要点：
  - 生命周期： 创建、复制、移动、删除
    - touch: 创建文件，支持一次性创建多个文件`touch list bin`
      - 语法：`touch [文件名]`
      - 功能：新建（文件不存在时创建新文件）/ 更新（文件存在更新时间戳）

    - cp: 复制文件与目录
      - 基本语法：`cp source destination`
        - 复制并粘贴到目标路径
        - 在目标路径后指定文件名即可重命名
        - 示例：`cp file.txt /tmp/new.txt`
      - 进阶用法：目录与属性
        - 语法：`cp -rp src_dir/ dest/`
        - `-r`/`/R`: 递归复制整个目录（必选）
        - `-p`: 保留权限、时间戳等元数据
        - `-a`: 递归复制整个目录（必选）
        - 建议组合使用`-rp`确保数据完整性 
      - 注意：复制目录时若漏掉`-r`选项，系统会报错并跳过该目录

    - mv: 移动与重命名（移动目录和文件逻辑一样）
      - 移动：`mv 源文件 目标目录`
      - 重命名：`mv 旧名称 新名称`
      - 逻辑：同一文件系统内仅修改目录项
      - 效率：执行速度快，无数据拷贝

    - rm: 删除和风险
      - 语法：`rm [options] <target>`
      - options:
        - `-r`(recursive): 递归删除目录
        - `-f`(force): 强制删除，忽略提示
        - `-i`(interactive): 交互模式，逐一确认
      - 示例：`rm config.json`, `rm -rf dist`
      - 注意：
        - 执行前确认：先使用ls命名确认路径及通配符的文件范围
        - 防范误删：生产环境建议开启-i选项或使用trash-cli等回收站工具
        - 建议：删除前先使用mv命名移动到/temp或使用回收站工具
     
  - 链接类型： 硬链接（Hard）\软链接（Soft）
    - 链接（Link）是Linux中访问文件的特殊路径，类似于快捷入口
    - 软链接（Symbolic Link）
      - 类似windows的快捷方式
      - 内部存储指向目标文件的路径
      - 目标文件被删除后链接失效
    - 硬链接（Hard Link）
      - 文件的另一个独立入口
      - 与原文件指向相同的Inode数据
      - 删除其中一个不影响文件数据使用
    - 应用场景
      - 简化长路径访问（创建快捷方式）
      - 软件库版本管理
      - 预防重要数据误删
    - 底层原理：Inode与链接的本质
      - Inode: 文件在磁盘上的唯一标识，存醋元数据
      - Hard Link：不同文件名指向同一个Inode
      - Symbolic Link: 独立文件，内容记录目标文件的路径
      - 核心差异：
        - 硬链接共享Inode,删除不影响原件
        - 软链接类似快捷方式，原件删除则失效（原文件和链接拥有独立的Inode指向原文件路径）

    - 创建链接：`ln`
      - 语法：`ln [源文件] [软件名]`
      - 注意： 默认创建硬链接，软链接必须使用`-s`选项（查看 `ls -l`）
      - 示例：
        - 创建：`ln -s /etc/nginx/conf.d/default.conf my_nginx`
        - 使用：直接通过`my_nginx`直接访问该文件

    - 注意：
      - 推荐使用软链接（更灵活，跨系统/目录）

  - 必备命令：`touch`, `cp`, `mv`, `rm`, `ln`

## 文件查看全家桶

- 目的：
  - 掌握不同场景下的工具选择
  - 理解全量读取与分页读取差异
  - 学会定位查看文件头与尾部
  - 掌握实战：实时动态监控日志
  - 建立系统性命令行操作思维

- 示例

``` bash
cat log.txt
more log.txt
less log.txt
```

- cat: 一次性读取
  - 核心定义：全量内容一次性输出到屏幕
  - 适用场景：短小配置文件、临时内容查看
  - 局限性：大文件滚动过快，难以阅读

- more: 基础的分页查看器
  - 痛点解决：
    - 解决cat命令查看长文件时的刷屏功能
    - 按屏幕高度分页展示，支持停顿阅读
  - 常用交互
    - Space空格键： 向下翻一页
    - Enter回车键：向下滚动一行
  - 进度显示与局限性
    - 查看进度：终端左下角实时显示当前内容的百分比
    - 浏览器局限：仅支持向后/向下翻页，无法回溯已经阅读的内容

- less: 强大的交互式分页神器
  - 核心优势：
    - 功能远超more
    - 极速加载：不读取全文件，秒开大日志
    - 双向翻页：支持PageUp/b向上翻页
  - 交互式搜索
    - /关键字：向下搜索指定文本
    - n / N: 查找下一个/上一个
  - 快捷键
    - g开头
    - G末尾
    - q退出

- head/tail: 精准切片查看
  - head: 查看文件开头（默认10行）
  - tail: 查看文件结尾（默认10行）
  - -n参数: 自定义切片行数
  - 示例
    `head -n 5`
  - 适用场景
    - 查看配置文件版本头信息
    - 实时追踪系统日志末尾动态

- 实时监控tail -f
  - 实时追踪：-f选项保持连接同步输出内容
  - 排除故障神器：线上故障实时观测的最佳手段
  - 快捷退出：使用Ctrl + C组合中指监控
  - 实战：监控系统消息日志
    `tail -f /var/log/messages`
