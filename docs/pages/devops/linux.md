# Linux 

## Base

### 基本语法

命令 -选项 参数（指定命令作用的对象如文件名或路径）
```bash
ls -l /home
```

## 提升效率

1. Tab（补全命令名、文件名、目录路径）
- 单次tab自动补全唯一匹配项
- 双次tab显示所有可能出现的列表，用于存在多项匹配时

2. history历史命令
- 查看历史`history`
- 快速执行：查看历史后通过!编号快速执行如：`!22`
- 快捷切换：通过上下键快捷切换历史

3. 搜索与快速匹配
- Ctrl+R反向搜索（实时匹配历史命令， 输入关键字即可定位，按Enter执行）
- `!!`快速执行（重新执行上一条命令， `sudo!!` -> 快速以管理员权限重试命令）
- `history -c`用于清空当前会话的历史缓存，常用于敏感操作后的痕迹清理或环境初始化，确保操作历史不被泄漏

4. 帮助系统
- `--help`如`ls --help`
- `man`手册如`man ls`查询命令的详细信息
- `tldr`只展示常用的高频实战范例，如`tldr tar`

## 系统目录结构

Linux的哲学：一切皆文件（统一操作接口使用命令全局控制系统）

- /：根目录
- /etc: 系统配置文件（修改记得备份）
   - /etc/hosts: 静态域名解析
   - /etc/passwd: 存储用户信息
   - /etc/skel: 用户创建时系统自动从该目录复制拷贝文件

- /root: 管理员目录

- /home: 用户主目录：个人数据(随意弄不会影响全局)
  - /home/user: 创建一个用户就会生成一个/home/user

- /bin: 二进制可执行文件，通用基础命令（ls、cat等）

- /sbin: 系统管理命令（ip、 fdisk等）

- /dev: 设备目录（硬盘等）

- /usr(Unix system resource): 用户应用程序（软件： 办公、编程软件等）目录，类似windows的Program Files,是系统中最庞大的目录之一
  - /usr/local: 个人软件等
  - /usr/bin: 命令
  - /usr/lib: 库

- /var: 可变数据目录
  - /var/log: 日志
  - /var/mail: 代收发邮件
  - /var/cache: yum缓存

- /opt: 第三方等预编译软件

- /temp: 临时文件

## 目录管理

- pwd: Print Working Directory
  - 显示当前工作目录的绝对路径
  - 在复杂目录结构中快速定位

- cd: Change Directory
  - 切换当前工作目录
  - 语法
    `cd [目标路径（相对/绝对）]`
  - 快捷跳转(`~`: 用户家目录， `-`： 上一次所在目录)
    - `cd ~` / `cd`: 快速回到用户家目录
    - `cd -` : 在两个目录间切换
    - `cd ..` : 返回上一级

- ls: List
  - 列出目录内容
  - 查看当前目录下的非隐藏内容
  - 基础语法`ls [目录路径]`
  - 常用选项(选项可以组合使用： `ls -lah`， `ls -ltr`)
    - `-l`: 长格式显示详细信息
    - `-a`: 包含隐藏文件（以.开头）
    - `-h`: 文件大小易读化（KB/MB）
    - `-t`: 按修改时间排序
    - `-r`: 反转排序结果

- mkdir: Make Directory
  - 创建新目录
  - 语法`mkdir [目录名]`
    - 目录名严格区分大小写
    - 避免使用特殊字符及空格
  - 高级用法
    - `mkdir -p`: 递归创建
      - 普通创建局限：父目录不存在时会报错
      - `-p`(parent选项)：自动补全中间路径
      - 优势：一次性构建完整目录
      - 例子：`mkdir -p project/src/main/java`

- rmdir: Remove Directory
  - 限制：仅能删除空目录
  - 安全：有效防止误删
  - 报错： 目录非空报错

## 文件基本操作

- 核心要点：
  - 生命周期： 创建、复制、移动、删除
    - touch: 创建文件，支持一次性创建多个文件`touch list bin`
      - 语法：`touch [文件名]`
      - 功能：新建（文件不存在时创建新文件）/ 更新（文件存在更新时间戳）

    - cp: 复制文件与目录
      - 基本语法：`cp source destination`
        - 复制并粘贴到目标路径
        - 在目标路径后指定文件名即可重命名
        - 示例：`cp file.txt /tmp/new.txt`
      - 进阶用法：目录与属性
        - 语法：`cp -rp src_dir/ dest/`
        - `-r`/`/R`: 递归复制整个目录（必选）
        - `-p`: 保留权限、时间戳等元数据
        - `-a`: 递归复制整个目录（必选）
        - 建议组合使用`-rp`确保数据完整性 
      - 注意：复制目录时若漏掉`-r`选项，系统会报错并跳过该目录

    - mv: 移动与重命名（移动目录和文件逻辑一样）
      - 移动：`mv 源文件 目标目录`
      - 重命名：`mv 旧名称 新名称`
      - 逻辑：同一文件系统内仅修改目录项
      - 效率：执行速度快，无数据拷贝

    - rm: 删除和风险
      - 语法：`rm [options] <target>`
      - options:
        - `-r`(recursive): 递归删除目录
        - `-f`(force): 强制删除，忽略提示
        - `-i`(interactive): 交互模式，逐一确认
      - 示例：`rm config.json`, `rm -rf dist`
      - 注意：
        - 执行前确认：先使用ls命名确认路径及通配符的文件范围
        - 防范误删：生产环境建议开启-i选项或使用trash-cli等回收站工具
        - 建议：删除前先使用mv命名移动到/temp或使用回收站工具
     
  - 链接类型： 硬链接（Hard）\软链接（Soft）
    - 链接（Link）是Linux中访问文件的特殊路径，类似于快捷入口
    - 软链接（Symbolic Link）
      - 类似windows的快捷方式
      - 内部存储指向目标文件的路径
      - 目标文件被删除后链接失效
    - 硬链接（Hard Link）
      - 文件的另一个独立入口
      - 与原文件指向相同的Inode数据
      - 删除其中一个不影响文件数据使用
    - 应用场景
      - 简化长路径访问（创建快捷方式）
      - 软件库版本管理
      - 预防重要数据误删
    - 底层原理：Inode与链接的本质
      - Inode: 文件在磁盘上的唯一标识，存醋元数据
      - Hard Link：不同文件名指向同一个Inode
      - Symbolic Link: 独立文件，内容记录目标文件的路径
      - 核心差异：
        - 硬链接共享Inode,删除不影响原件
        - 软链接类似快捷方式，原件删除则失效（原文件和链接拥有独立的Inode指向原文件路径）

    - 创建链接：`ln`
      - 语法：`ln [源文件] [软件名]`
      - 注意： 默认创建硬链接，软链接必须使用`-s`选项（查看 `ls -l`）
      - 示例：
        - 创建：`ln -s /etc/nginx/conf.d/default.conf my_nginx`
        - 使用：直接通过`my_nginx`直接访问该文件

    - 注意：
      - 推荐使用软链接（更灵活，跨系统/目录）

  - 必备命令：`touch`, `cp`, `mv`, `rm`, `ln`

## 文件查看全家桶

- 目的：
  - 掌握不同场景下的工具选择
  - 理解全量读取与分页读取差异
  - 学会定位查看文件头与尾部
  - 掌握实战：实时动态监控日志
  - 建立系统性命令行操作思维

- 示例

``` bash
cat log.txt
more log.txt
less log.txt
```

- cat: 一次性读取
  - 核心定义：全量内容一次性输出到屏幕
  - 适用场景：短小配置文件、临时内容查看
  - 局限性：大文件滚动过快，难以阅读

- more: 基础的分页查看器
  - 痛点解决：
    - 解决cat命令查看长文件时的刷屏功能
    - 按屏幕高度分页展示，支持停顿阅读
  - 常用交互
    - Space空格键： 向下翻一页
    - Enter回车键：向下滚动一行
  - 进度显示与局限性
    - 查看进度：终端左下角实时显示当前内容的百分比
    - 浏览器局限：仅支持向后/向下翻页，无法回溯已经阅读的内容

- less: 强大的交互式分页神器
  - 核心优势：
    - 功能远超more
    - 极速加载：不读取全文件，秒开大日志
    - 双向翻页：支持PageUp/b向上翻页
  - 交互式搜索
    - /关键字：向下搜索指定文本
    - n / N: 查找下一个/上一个
  - 快捷键
    - g开头
    - G末尾
    - q退出

- head/tail: 精准切片查看
  - head: 查看文件开头（默认10行）
  - tail: 查看文件结尾（默认10行）
  - -n参数: 自定义切片行数
  - 示例
    `head -n 5`
  - 适用场景
    - 查看配置文件版本头信息
    - 实时追踪系统日志末尾动态

- 实时监控tail -f
  - 实时追踪：-f选项保持连接同步输出内容
  - 排除故障神器：线上故障实时观测的最佳手段
  - 快捷退出：使用Ctrl + C组合中指监控
  - 实战：监控系统消息日志
    `tail -f /var/log/messages`

## 管道与重定向

- 单一职责：每个命令只做好一件事
- 协作桥梁：重定向与管道的引入
- 掌握核心：理解Linux数据流向控制
执行命令 -> 数据读取 -> 逻辑判断 -> 输出结果

- Linux的三大数据流
  - 标准输入（stdin）0 进程接收数据的主要途径
  - 标准输出（stdout）1 进程输出结果的默认通道
  - 标准错误（stderr）2 独立于输出的报错专用流
  输入 -> 计算机处理流程 -> 输出 / 错误

- 输出重定向
  - 覆盖重定向：`>`
    - 示例：清空目标文件原内容写入新数据`echo 'hello' > test.txt`
  - 追加重定向：`>>`
    - 示例：在文件末尾添加内容，保留原有数据`ls -l >> list.txt`
  - 核心应用场景
    - 结果持久化：将运算结果存入文件
    - 日记记录：持续追踪系统操作记录
命令输出 -> 目标文件

- 错误重定向与合并输出
  - 捕获错误流（`2>`）: `ls no_file 2> error.log`
  - 合并流（`2>&1`）: `command > out.log 2>&1`
  - 静默处理（`/dev/null`）: `command > /dev/null 2>&1`

- 管道符`|`
  - 工作原理：stdout直接链接到stdin
  - 工业比喻：流水线上的半成品传递
  - 核心价值：内存直接传递，无需临时文件
  命令A(stdout) -|--> 命令B(stdin)
  - 管道符实现了数据的分阶段加工，将复杂任务拆解为简单的命令组合
  - 案例
    - 进程与过滤
      - 查询进程`ps aux | grep nginx` 精准过滤特定服务
      - 统计数量`ls -l | wc -l` 排除干扰统计行数
      - 日志监控`tail -f logs | grep 'Error'` 实时捕获关键报错
    - 多重管道与tee命令：组合原子命令构建强大的自动化处理逻辑
      - 多重管道`cat access.log | grep '404' | awk 'pring $1' | sort | uniq -c`
      - tee命令：管道中的t型分流
        - 将文件输出到output的同时输出到终端`ls -l | tee output.txt | grep 'txt'`

- 综合案例：读取日志文件中访问量最大的前5个ip
`awk 'print $2' access.log | sort | uniq -c | sort -nr | head -n 5`
- `awk 'print $2' access.log`: 提取日志中的第二列（ip）
- `sort`: 将相同的IP排列在一起
- `uniq -c`: 统计每个IP出现的次数
- `sort -nr`: 根据统计数字进行从大到小逆序排序
- `head -n 5`: 取出排列结果的前5行

## grep与正则表达式

- grep: 文本搜索利器（global regular expression print：全局正则表达式版本并打印）
  - 核心功能：在文本中检索特定模式并输出
  - 日志分析：快速追踪系统异常与关键请求
  - 配置管理：过滤沉余注释，精准定位参数
  - 代码审计：批量检索敏感函数与关键词
  - 基本语法：`grep [选项] 模式 [文件路径]`
  - 选项
    - -i: 忽略大小写
    - -v: 反向匹配，输出不包含模式的行
    - -n: 显示行号
    - -c: 统计匹配行数
    - -l: 仅输出包含匹配行的文件名
  - 组合使用
    - 示例：`grep -in 'error' access.log` 忽略大小写显示行号

- 正则表达式（从精确匹配到模式匹配）
  - 核心定义：描述文本特征的逻辑公式
  - 字符构成：普通字符 + 元字符
    - 元字符：
      - `.`：匹配除换行符外的任意单个字符
      - `*`(定义重复次数，不同与Shell的通配符匹配任意文件): 匹配前一个字符出现零次或多次
      - `+`: 匹配前一个字符出现一次或多次
      - `?`: 匹配前一个字符出现零次或一次
      - `|`: 或操作，匹配多个模式中的任意一个
      - `{n}`: 匹配前一个字符出现n次
    - 边界锚点：
      - `^`: 匹配字符串开头，限定匹配必须从行首开始
      - `$`: 匹配字符串结尾，限定匹配必须在行结尾结束
      - `^...$`: 匹配以...开头以...结尾的字符串

- 扩展正则表达式与 grep -E 
  - ERE核心优势
    - 语法简化：无需反斜杠转义+、？、|、{}
    - 命令等价：`grep -E`效果等同于egrep
    - 逻辑增强：支持更复杂的逻辑分支与嵌套
    - 架构规范：现代Linux环境的首选正则标准
    - 示例：`grep -E 'error|warning' access.log` 匹配error或warning

## 文件查找find

- 核心优势：多维度属性搜索（不仅限于文件名检索，更支持基于修改时间、文件大小、权限及所有者等属性的深度扫描）
- 基本语法：`find [路径] [测试条件] [处理动作]`
  - 默认路径行为：若不指定路径，默认为当前目录（.）
  - 递归查找特性：自动遍历起始路径下的所有子目录
  - 提示：find命令在执行时，按顺序解析路径，测试条件并执行对应动作

- 按名称查找-name、-iname
  - `-name`: 精确匹配文件名严格区分大小写
  - `-iname`: 忽略大小写匹配文件名
  - 注意：使用通配符时必须用引号包裹`".log"`,防止Shell在find命令运行前将其提前解析，确保匹配逻辑由find执行
  - 示例：`find . -name "*.log"` 查找当前目录下所有以.log结尾的文件

- 按类型查找-type
  - 核心参数
    - `f`: 普通文件
    - `d`: 目录
    - `l`: 符号链接

    - `c`: 块设备文件
    - `b`: 块设备文件
    - `s`: 套接字文件
    - `p`: FIFO文件
    - `k`: 硬链接文件
  - 示例：`find . -type d -name "backup"` 查找当前目录下所有名为backup的目录

- 按时间查找-mtime、-ctime、-atime
  - 核心参数
    - `-mtime`: 最近修改时间（单位：天）
    - `-ctime`: 最近创建时间（单位：天）
    - `-atime`: 最近访问时间（单位：天）
  - 示例：`find . -mtime 7` 查找当前目录下最近7天修改的文件
  - 示例：`find . -mtime -7` 查找当前目录下7天内修改的文件
  - 示例：`find . -mtime +30` 查找当前目录下超过30天未修改的文件
  - 示例：`find . -ctime 7` 查找当前目录下最近7天创建的文件
  - 示例：`find . -atime 7` 查找当前目录下最近7天访问的文件

- 按大小查找-size
  - 核心参数
    - `-size`: 文件大小（单位：字节）
  - 常用单位：
    - `k`: 千字节
    - `M`: 兆字节
    - `G`: 吉字节
  - 范围匹配
    - `+`: 大于
    - `-`: 小于
  - 示例：`find . -size +100M` 查找当前目录下所有大小超过100MB的文件
  - 示例：`find . -size -100M` 查找当前目录下所有大小小于100MB的文件

- 逻辑组合：与、或、非
  - 核心参数
    - `-a`: 与操作，同时满足多个条件
    - `-o`: 或操作，满足任意一个条件
    - `-!` / `-not`: 非操作，排除满足条件的文件
  - 示例：`find . -name "*.log" -a -mtime 7` 查找当前目录下所有以.log结尾的文件且最近7天修改的文件
  - 示例：`find . -name "*.log" -o -mtime 7` 查找当前目录下所有以.log结尾的文件或最近7天修改的文件
  - 示例：`find . -name "*.log" -a -mtime 7 -o -size +100M` 查找当前目录下所有以.log结尾的文件且最近7天修改的文件或大小超过100MB的文件
  - 注意：使用括号`\(\)`括起来的条件，会优先执行，确保逻辑顺序正确,需要转义
  - 优先级： 括号 > 非 > 与 > 或

- 综合案例：在/var/log目录下查找大于500MB而且7天内修改过的所有以.log结尾的文件
  - 示例：`find /var/log -name "*.log" -mtime -7 -size +500M` 查找/var/log目录下所有以.log结尾的文件且最近7天修改的文件或大小超过500MB的文件
  - 注意：1M = 1048576字节; 1k = 1024字节

- 动作处理：-exec
  - 核心参数
    - `-exec`: 执行指定命令处理找到的文件
  - 语法：`find [路径] [测试条件] -exec [命令] {} \;`
    - `{}`: 代表find查找到的每一个文件名
    - `\;`: 告诉find命令该动作执行结束
  - 示例：`find . -name "*.log" -exec rm {} \;` 删除当前目录下所有以.log结尾的文件
  - 安全实践
    - 预览先行：执行rm前，先用-ls确认文件列表
    - 交互确认：使用-ok替代-exec,逐一手动确认操作
    - 效率进阶：海量文件处理建议使用xargs

- 高频案例
  - 清理过期日志：在/var/log目录下删除大于7天且大于50M的文件
    `find /var/log -mtime +7 -size +50M -delete`
  - 批量权限修正：将当前目录777权限统一修改为644
    `find . -perm 777 -exec chmod 644 {} +`
  - 定位配置文件：/etc及其子目录以.conf结尾的文件
    `find /etc -name "*.conf"` 
  
## 磁盘空间管理概览

核心目标：规避存储溢出故障（定期巡检）

- 容量监控：使用du/df命令
  - df：disk free
    - 报告文件系统磁盘空间
    - 常用选项`df -h`以GB/MB显示易读格式
  - du：disk use 
    - 统计目录/文件真实占用
    - 实用技巧
      - `du -sh`: 汇总当前目录大小
      - `--max-depth=1`:定位大目录（第一级）
      - `sort -hr`:结果按容量降序排列 
  - 建议：先用df查看分区百分比，再用du定位大目录

- 挂载管理：使外部存储设备可用
  - 硬件设备必须挂载到目录树中的某个节点后才能被访问（/mnt或/data）
  - 挂载点建议使用空目录
  - mount命令
    - 查找设备名：`lsblk` ，`fdisk -l`确定设备
    - 准备挂载点：`mkdir /mnt/usb`创建入口目录
    - 执行挂载：`mount /dev/sdb1 /mnt/usb`
    - 验证状态：`df -h`确定容量与挂载点
  - umount命令
    - 卸载挂载点：`umount /mnt/usb`
    - 卸载设备名：`umount /dev/sdb1`
    - 卸载时报错：`target is busy`的原因
      - 当前用户工作目录在这个挂载点或者挂载点子目录内，解决：cd到其他目录
      - 后台程序正在打开、读取或者写入该挂载点下的文件（lspf /mnt/storage）
      - 该目录下存在子挂载点（先卸载子目录）
      - 挂载点通过nfs或者samba被共享访问

## 文件打包与压缩

核心价值：节省空间、加快传输、规范备份

- 打包：将多个文件或目录整合为一个文件，不改变数据总量，仅便于传输
- 压缩：利用算法剔除冗余，减小磁盘空间占用，需消耗cpu资源进行运算处理
- 格式
  - `.tar`: 仅打包，备份原始目录结构
  - `.tar.gz` / `.tgz`: 打包并压缩，平衡速度与效率
- tar命令
  - 语法：`tar 选项 压缩包名 源文件或目录`
  - 参数
    - `-c`: 创建新的归档文件（Create）
    - `-x`: 从归档文档中解开文件（Extract）
    - `-t`：列出归档内容（List）
    - `-v`：显示详细处理过程（Verbose）
    - `-f`：（必选）指定归档文件名（File），必须紧跟文件名
  - 案例
    - `tar -cvf test.tar /home/test/`
  - Gzip压缩，关键参数-z，特点：压缩速度快，压缩率平衡`.tgz`
    - `tar -zcvf test.tgz /home/test/`
  - 极限压缩Bzip2, 关键参数-j,调用bzip2,后缀`.bz2`
    - `tar -jcvf test.bz2 /var/log`
    - 特点
      - 高压缩率：通常优于gzip,显著节省磁盘空间
      - 适用场景：文件较大且对压缩时间不敏感
  
  - 解包（-xvf）
    - `-x`: 解开归档
    - `tar -xvf test.tar`
    - 规范：解压前先预览，防止压缩包爆炸`tar -tvf test.tar`
    - 指定解压路径(-C)：`tar -zxvf test.tar.gz -C /tmp`
  - 安全建议
    - 使用相对路径：打包前进入目录，避免解压时产生多余层级
    - 文件名使用时间戳备份：方便追溯
    - 权限保留属性：tar命令保留文件原始权限
    - 文件排除选项：使用`--exclude`选项过滤日志、缓存等不需要打包的子目录

## 效率提升与系统路径

- alias: 为命令起个别名
  - 定义：命令的快捷方式
  - 价值：简化冗长或带有复杂参数的常用操作
  - 示例：`ll `:`ls -lh`
  - 语法：`alias` 别名='原命令'
    - `alias c='clear'`
    - `alias ll='ls -lh'`
  - 查看别名：`alias`
  - 取消别名：`unalias c`
  - 注意：当前定义的别名仅在当前窗口回话内有效，重启或关机后失效，需要配置环境变量以持久化

- PATH变量
  - 查找逻辑：系统并非盲目搜索，而是按路径检索
  - 变量结构：冒号分隔的有序目录集合`/usr/bin:/usr/local/bin`
  - 检索顺序：自左向右依次查找，命中即停止
  - 失败提示：路径变量结束未找到则报错(`command not found`)

  - 查看与分析当前PATH`echo $PATH`

- 让配置永久生效
  - 核心机制：Shell启动时自动加载配置
  - 关键文件：~/.bashrc(当前用户级)
  - 操作流程
    - vim 编辑配置文件
    - 在末尾添加alias或修改PATH
    - `:wq`保存后退出编辑器
    - 立即应用配置`source ~/.bashrc`
  - 示例：添加自定义路径到PATH
    - 将个人脚本目录添加至系统搜索路径，实现任意位置直接运行
    - 将该命令配置在~/.bashrc中`export PATH=$PATH:~/bin`
    - 注意：必须包含$PATH,否则将覆盖原有路径导致系统基础命令失效

## Vim编辑器

要点：放弃死记，多实战形成肌肉记忆

- 三种工作方式
  - 命令模式：光标移动、删除、复制、粘贴
    - 文本输入技巧
      - i:在当前光标前插入
      - a:在当前光标后追加（Append）
      - o:在当前行下方另启新行插入
  - 插入模式：常规的文本输入与编辑
  - 末行模式：文件保存、退出、查找替换
    - 保存与退出
      - `:w`:保存
      - `:q`:退出
      - `:wq`退出保存
      - `:q!`强制退出不保存
    - 搜索与替换
      - /关键词（n下一个/N上一个）
      - `:%S`/旧内容/新内容/g全局替换`:%s/8090/8888/g`
    - 显示行好`:set nu`

- 三种模式切换(无论处在何种模式，按ESC即可返回命令模式)
  - 默认进入命令模式
  - 从命令模式进入插入模式按`i`，反过来按`ESC`
  - 从命令模式进入末行模式按`:`,反过来按`ESC`

- 光标移动与基础编辑
  - 基础移动：上`k`下`j`左`h`右`l`
  - 常用编辑指令
    - `dd`删除当前行，删除n行`ndd`
    - `yy`复制，`p`粘贴
    - `u`撤销改动（Undo）

- 案例：在配置文件末尾新增一行
  - `vim conf`按`G`直接进入文件末尾，按`o`在下方新增加一行,填写后按`ESC`然后`:wq`保存并关闭
