# Linux 

## Base

### 基本语法

命令 -选项 参数（指定命令作用的对象如文件名或路径）
```bash
ls -l /home
```

## 提升效率

1. Tab（补全命令名、文件名、目录路径）
- 单次tab自动补全唯一匹配项
- 双次tab显示所有可能出现的列表，用于存在多饿匹配时

2. history历史命令
- 查看历史`history`
- 快速执行：查看历史后通过!编号快速执行如：`!22`
- 快捷切换：通过上下键快捷切换历史

3. 搜索与快速匹配
- Ctrl+R反向搜索（实时匹配历史命令， 输入关键字即可定位，按Enter执行）
- `!!`快速执行（重新执行上一条命令， `sudo!!` -> 快速以管理员权限重试命令）
- `history -c`用于清空当前会话的历史缓存，常用于敏感操作后的痕迹清理或环境初始化，确保操作历史不被泄漏

4. 帮助系统
- `--help`如`ls --help`
- `man`手册如`man ls`查询命令的详细信息
- `tldr`只展示常用的高频实战范例，如`tldr tar`

## 系统目录结构

- /：根目录
- /etc: 系统配置文件（修改记得备份）
   - /etc/hosts: 静态域名解析
   - /etc/passwd: 存储用户信息
- /home: 用户主目录：个人数据
- /bin: 二进制可执行文件
- /usr: 用户应用程序目录
- /var: 可变数据目录
