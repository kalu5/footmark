# Zabbix

- 企业级监控
  - 网络设备（交换机、路由器、ups、防火墙、上网行为管理等等）
  - 服务器

- 核心流程
  - 配置前端页面（Php、nginx），生成图形监控页
  - 安装数据库
  - 创建处理中心（server）,可配置多个（主、从关系，一个故障后另一个自动切换）
  - 创建agents客户端（监控数据上传）
  - 配置监控指标
  - 配置触发器
  - 触发动作
  - 关联用户
  - 添加告警媒介（企微机器人等）
  - 发送告警信息

- 监控原理

客户端上传监控数据 -> Server端监控异常指标 -> 触发 -> 通知关联人（机器人、消息等）
